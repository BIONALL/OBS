# Portal Siswa BION

Satu pintu layanan belajar online BION SD, SMP, dan SMA untuk siswa dan orang tua.

- **Frontend:** HTML, CSS, dan JavaScript statis di GitHub Pages
- **Backend:** Google Apps Script sebagai API JSON (Google Sheets + Drive)
- **Panel staf:** tambahkan `#staf` di akhir alamat portal

## Struktur

```
index.html        Kerangka halaman
css/style.css     Tampilan (design system "Lentera Belajar")
js/config.js      Alamat API Apps Script (GAS_URL)
js/app.js         Logika aplikasi & pemanggilan API
```
